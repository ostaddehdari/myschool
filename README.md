# MySchool — مدرسه من

Version 0.1.5 (cumulative). W00.01 bootstrap; W00.02 core schema; W00.03 capabilities; W00.04 REST and Jalali; W00.05 settings and audit log; W01.01 school profile.

Requires WordPress >=6.4 and PHP >=8.0. Admin menu: مدرسه من → مشخصات مدرسه. A WordPress media attachment can be used as a school logo. School profile columns are created by migration version 3 and saved through a nonce-protected admin-post handler. Plugin updates preserve data. Integration testing on live WordPress remains pending.
